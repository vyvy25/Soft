— Motion Principles

✓ DO

Subtle fade transitions, hover depth, slow ambient glow, staggered reveals on scroll, smooth parallax.

✗ DON'T

Bouncy playful springs, flashy color cycles, crypto-style hype animations, distracting micro-interactions.

CSS Variables

Drop into your :root. Production-ready tokens for any framework.

/* SoftFlex Design Tokens v1.0 */
:root {
  /* Surfaces */
  --bg-primary:    #070B14;
  --bg-secondary:  #0F172A;
  --bg-elevated:   #131C31;

  /* Accents */
  --accent:        #4F8CFF;
  --accent-glow:   #7AB8FF;
  --accent-cyan:   #3DD9FF;

  /* Text */
  --text-primary:  #F8FAFC;
  --text-secondary:#94A3B8;
  --text-tertiary: #64748B;

  /* Border */
  --border:        #1E293B;

  /* Type */
  --font-sans:     'Inter', sans-serif;
  --font-serif:    'Instrument Serif', serif;
  --font-mono:     'JetBrains Mono', monospace;

  /* Motion */

}
